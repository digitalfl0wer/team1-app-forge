# team1-app-forge

A todo list built as an **Atlassian Forge app inside Jira** — a panel on
an issue/project. Each team member's research topic ships as a working
layer of the app.

**v1 due: 10/13** — a working app where everyone can demo their topic.

## Getting started

1. Accept the repo invite
2. Connect your GitHub in TAP: **Settings → User → Profile → GitHub**
3. `git clone git@github.com:digitalfl0wer/team1-app-forge.git`
4. Pull before you work. One branch per task (e.g. `michael/frontend-stack`), PR to `main`.

## How we work

- GitHub is the source of truth — unpushed work isn't shared
- Decisions go in `docs/` the same day they're made
- Stack (frontend + backend) is decided together at kickoff
- Stuck? `@mention` a specialist in TAP or ask Chloe to route you
